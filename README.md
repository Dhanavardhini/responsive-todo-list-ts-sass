# Responsive To-Do List (TypeScript + Sass)

A simple and responsive To-Do List application built using **HTML**, **Sass (SCSS)**, and **TypeScript**.

---

## 🚀 Features

- ✅ Add new tasks
- 🧾 Mark tasks as completed
- ❌ Delete tasks
- 📱 Fully responsive design
- 🎨 Styled with Sass for modular, scalable CSS
- 🔒 Type-safe logic with TypeScript

---

## 🛠️ Tech Stack

- HTML5
- Sass (SCSS)
- TypeScript (compiled to JavaScript)
